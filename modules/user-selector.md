# Phase 2: 用户选择模型

## 目的
收集用户对模型、硬件规格、部署方式和目标镜像仓库的选择，为后续针对性解析和部署配置提供基础。

## 输入
- Phase 1 模型列表 JSON

## 执行位置
- 交互式问答（管理节点或本地终端）

## 步骤
1. 展示模型列表，提示用户输入序号或模型名称选择模型
2. 展示硬件规格选项：
   - A3：16 卡 NPU 服务器
   - A2：8 卡 NPU 服务器
3. 展示部署方式选项：
   - 单节点：使用 1 个节点部署
   - 多节点：使用多个节点进行分布式部署
   - PD分离：Prefill 和 Decode 节点分离部署
4. 提示用户输入目标镜像仓库地址（如 `harbor.example.com/library`）
5. 汇总并确认用户选择

## 输出
```json
{
  "selected_model": "GLM-5",
  "model_url": "GLM5.html",
  "hw_spec": "A3",
  "deploy_mode": "multi_node",
  "image_registry": "harbor.example.com/library"
}
```

## 失败处理
| 场景 | 处理方式 |
|-----|---------|
| 用户选择无效模型序号 | 提示重新输入，显示有效序号范围 |
| 硬件规格输入无效 | 默认提示 A3/A2 选项，要求重新输入 |
| 部署方式输入无效 | 默认提示单节点/多节点/PD分离选项，要求重新输入 |
| 镜像仓库地址格式错误 | 提示检查地址格式（不应包含镜像名和 tag） |
